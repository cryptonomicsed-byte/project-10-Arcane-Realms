OPTIONAL: ADD API KEY FOR FULL AI FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

To enable AI narration in multiplayer quests:

1. Copy .env.local.example to .env.local
   cp .env.local.example .env.local

2. Add your API credentials:
   
   NEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_key
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=your-project-id
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your-domain.firebaseapp.com
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your-bucket.appspot.com
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
   NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
   
   # Choose one:
   NEXT_PUBLIC_Z_API_KEY=sk-proj-... (OpenAI)
   # OR
   NEXT_PUBLIC_Z_API_KEY=sk-ant-... (Anthropic)
   # OR
   NEXT_PUBLIC_Z_API_KEY=AIza... (Google)
   # OR just use Ollama locally (free!)

3. Restart: npm run dev

TROUBLESHOOTING:
━━━━━━━━━━━━━

Issue: npm install is slow
→ Use: pnpm install (faster package manager)

Issue: Port 3000 already in use
→ Run: npm run dev -- -p 3001

Issue: Multiplayer not syncing
→ Check: Firebase credentials in .env.local

Issue: AI not responding
→ Verify: API key is correct in .env.local

Issue: Character not loading
→ Open: Browser console (F12) for errors
